# Legacy

Planning documents from before the current direction. Kept because they
record how the product got here, not because they describe it.

| File | Written | Superseded by |
|------|---------|---------------|
| `brainstorm.md` | July 2026 | The archive is no longer the product. It is the input to an idea. |
| `signal.md` | March 2026 | Office-hours validation of the archive-as-product framing. |

Where they contradict the code, the code is right.

**What changed.** Both documents assume Naru is a place saved things go:
you share to it, it files them, you browse the grid. The product now
assumes the opposite. Your saves are already spread across Instagram,
TikTok, YouTube, Spotify, X and Are.na, and Naru pulls them in so it can
answer a different question: given everything you have saved, what should
you build? A thought typed into the bar gathers the saves that argue for
it, against it, and around it, and hands you a brief.

Current design decisions live in `DESIGN.md`. Process lessons live in
`gotchas.md`. Both are kept out of git.
